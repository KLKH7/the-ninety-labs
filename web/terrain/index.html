How it's built. Height is threat: every fifth frame, the ball's spot is valued with the engine's possession-value table for the team that has it, then summed per minute and per 5 m strip of pitch. Home attacks toward the far end. A turning point is a minute where the side on top changes and the new side stays on top for at least 5 minutes; a swing inside one side's spell, or a shorter flicker, is not one. Each card is a cue written by code (ninety/agents/cues.py) from the events of the 3 minutes before it, and passes the fact-checking agent's number check: every count and minute it states is read off the events it cites.

Limits. The default file, seed 7, is a simulated 0–0 with two shots, so the shape is about territory and pressure, not goals. The threat table comes from docs/eval/possession-value.md and has not settled yet. The repo has no halves yet, so nobody switches ends.
