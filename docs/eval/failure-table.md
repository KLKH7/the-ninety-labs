Generated by `uv run python -m ninety.eval.workflow_failures` (offline, byte for byte; `--check` fails if this file
is stale, as `tests/test_workflow_failures.py` does). Each row runs the workflow itself
(`ninety/agents/workflow.run_workflow`: template graphics, Analyst, Tactician, Challenger, the
fact-checking agent with its confidence gate, Producer) on the M1 clip's detected events
(`seed900001`, minute 2), with one failure injected at the model boundary.
The Judge is the real wrapper (its retry, timeout and verdicts) around a stand-in agent; the
other models are scripted, and the Personalizer's Spanish is the English marked `[es] `.

is `docs/eval/failure-table-m1.md`.

**Recovered: 4 of 4** injected failures. A row recovers when every template
graphic stays on air (less those on an unsure detection, which the confidence gate keeps off
the screen), every aired text passes the code checks again, the claim ends exactly as it must
(held; verified when only the Personalizer failed, since the insight needs no Personalizer),
the failure's own fallback is marked in the trace, and a fallback badge is on screen (the
cue's `fallback`, which the viewer draws); the baseline has neither, and airs every profile's
variant in its own language.
In 1 of 5 rows the Spanish variants are held, since a variant airs
only in its own language: in 1 the Personalizer was down and its fallback is the
English text; in 0 the Personalizer answered and its Spanish did not pass.

## Budgets

- The Judge: 15 s per call in production, retried 1
  time(s), then the claim is held (fail closed).
  Here 0.05 s, so the timeout row runs the same code path in a blink.
- The Personalizer: `personalizer.core.BUDGET_S` per call in production; on a timeout, a 5xx or
  a refused connection the in-process fallback answers (the verified text), here after the
  refusal, so the row takes milliseconds.
- A writer (Analyst, Tactician, Challenger): 60 s in production (`workflow.MODEL_TIMEOUT_SECONDS`), then its claim is held and the template stays.
- The confidence gate: a claim citing a detection below 0.5 is held before the Judge
  is asked, and never rewritten; a template graphic is drawn only for a detection at or above it.

Latencies are not measured here: the models are stand-ins, so a time would describe the stand-in.
