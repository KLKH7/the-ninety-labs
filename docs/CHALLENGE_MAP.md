mark a row `planned` until it runs in the demo. Milestones are defined in [PLAN.md](PLAN.md#milestones).

evidence file); **in progress** (part runs on `main`, or the work is in an open pull request; the
row says which part); **planned** (not built). Audited against `main` at `b4d9402` on Oct 19.
